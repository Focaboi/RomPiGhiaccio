>### 🚧 Work in Progress — Progetto in fase di sviluppo e refactoring attivo
# RomPiGhiaccio

il titolo deve la sua nascita alla fortunata coincidenza tra lo scopo del progetto e la prima parola contenente RPG di senso compiuto sovvenutami.

### Descrizione

un gioco di ruolo a turni, con elementi procedurali, nel quale lo scopo è di salvare il mondo dal gelo che lo avvolge.

### Stack tecnologico

- Java
- Git

### Stato dell'arte

ad è presente una struttura gerarchica con classi e poche interfacce, un sistema di dadi e una prima implementazione di talenti per stabilire casualmente o arbitrariamente le statistiche di mostri ed eroi, un inventario per custodire gli oggetti.

### Roadmap

- revamp del sistema di combattimento -> indipendente dal lancio di dadi
- iniziativa e metrica del tempo di gioco
- combattimento con uno o più nemici e risoluzione dello scontro
- eventi testuali procedurali
- salvataggio sessione e persistenza (plausibilmente mySQL)
- Bossfight e classificazione dei nemici
- test operativi Junit
